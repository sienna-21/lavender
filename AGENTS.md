## Application rules
- Keep the Wednesday gift at `/` and the full letter at `/poem`, using TanStack links so each is independently reachable.
- Draw decorative rabbits, bows, flowers, and clouds with simple SVG shapes and semantic CSS tokens to preserve the intentional handmade aesthetic.
- Keep the supplied poem in a browser-safe data module with stanza breaks preserved so presentation cannot alter its wording.
